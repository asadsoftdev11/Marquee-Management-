# MarqueeManagement
This project is a Marquee (Event Hall) Management System where:  The admin creates and manages marquees (event halls).  The system manages menu categories (Starter, Main Course, Dessert, etc.).  Under each category, menu items are created with prices.  Customers are registered in the system.  When a customer books a marquee for an event:  They select the event date.  Enter number of guests.  Choose food items from the menu.  The system calculates total cost (hall + food).  The booking is saved and tracked with a status (Pending, Confirmed, Completed).  So basically:
